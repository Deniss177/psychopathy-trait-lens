# Psychopathy Trait Lens

Claude skill, kas analizē publisku personu publisko saturu, meklējot ar psihopātiju saistītas uzvedības un valodas pazīmes (bez diagnozes), lai saprastu destruktīvus modeļus un pasargātu sevi. Tas ir izglītojošs un aizsargājošs rīks, nevis diagnostikas rīks.

## Uzstādīšana

**Claude Code:**

```bash
git clone https://github.com/Deniss177/psychopathy-trait-lens ~/.claude/skills/psychopathy-trait-lens
```

**Claude.ai:** Settings → Capabilities → Skills → augšupielādē šo mapi kā ZIP.

**Cits AI (ChatGPT, Gemini u.c.):** `SKILL.md` ir pašpietiekams, to var ielīmēt kā custom instructions vai sarunas sākumā.

## Lietošana

```
/psychopathy-trait-lens analizē [publiska persona] publisko saturu: ...
```

Nav diagnozes rīks. Neizmanto privātpersonu profilēšanai. Sk. atrunu failā [LICENSE](LICENSE).
